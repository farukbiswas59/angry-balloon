# Android and AdMob

The native Android project, ads, loading screen, landscape setup and phone-hosted LAN mode are now implemented.

Use [ANDROID-RELEASE-GUIDE.md](ANDROID-RELEASE-GUIDE.md) for the APK/AAB files, privacy-page hosting, AdMob configuration, testing, signing backup and complete Play Console publishing process.

Configuration is in `mobile/android-config.json`; build using `npm run build:android:debug` or `npm run build:android:release`.
